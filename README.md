# Email Classifier

A lightweight email-categorization web app. Paste any email body and the model labels it as **Spam**, **Work**, **Personal**, or **Promotions** with per-class confidence scores.

Built with scikit-learn (TF-IDF + Logistic Regression) and a small Flask UI.

## Stack

- Python 3.10+
- scikit-learn — TF-IDF vectorizer + Logistic Regression pipeline
- Flask — single-page web UI + JSON API
- joblib — model persistence

## Quickstart

```bash
git clone https://github.com/HemanthKumar52/Email-Classifier.git
cd Email-Classifier

python -m venv .venv
. .venv/Scripts/activate        # Windows PowerShell: .venv\Scripts\Activate.ps1
# source .venv/bin/activate     # macOS/Linux

pip install -r requirements.txt

python train.py                 # trains and writes model.joblib
python app.py                   # serves http://localhost:5000
```

## API

```
POST /api/classify
Content-Type: application/json

{ "text": "Congratulations! You won a $1000 gift card. Click here." }
```

Response:

```json
{
  "prediction": "spam",
  "scores": [
    { "label": "spam",       "confidence": 0.91 },
    { "label": "promotions", "confidence": 0.05 },
    { "label": "work",       "confidence": 0.02 },
    { "label": "personal",   "confidence": 0.02 }
  ]
}
```

## Dataset

`data/emails.csv` ships with a small balanced corpus (~60 examples across 4 classes) so the project runs out of the box. For real use, replace it with a larger dataset (e.g. Enron, SpamAssassin, or your own labeled inbox export) and re-run `python train.py`.
